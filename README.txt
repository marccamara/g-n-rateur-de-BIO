🚀 BIO CREATOR – Installation (Windows → iPhone jailbreak)

1️⃣ Installe les dépendances :
   pip install flask
   npm install -g @capacitor/cli
   npm install

2️⃣ Lance le serveur local :
   python app.py
   (ouvre http://127.0.0.1:5000)

3️⃣ Prépare pour iOS :
   npx cap init
   npx cap add ios
   npx cap copy
   npx cap open ios

4️⃣ Compile l’IPA dans Xcode :
   Product > Archive > Export .ipa

5️⃣ Transfère sur ton iPhone jailbreak :
   via Filza ou TrollStore
